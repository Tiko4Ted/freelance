# Repository Instructions

## Branch Rule

- Do not make changes on `main`.
- All subsequent work in this repository must happen on the `fixes` branch.
- If a future session starts on any branch other than `fixes`, switch to `fixes` before editing, committing, or pushing.
- Push changes to `origin/fixes`; do not push feature or fix work to `origin/main` unless explicitly instructed.
